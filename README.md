# Alternativee — experiência digital

Proposta navegável de modernização para a Alternativee, com página inicial editorial e página de produto dedicada ao Tissot PRX Powermatic 80 Titanium.

## Apresentação

- [Página inicial](https://neskenfrederico-gif.github.io/alternativee-experiencia-digital/)
- [Página do relógio](https://neskenfrederico-gif.github.io/alternativee-experiencia-digital/relogio.html)

As páginas públicas não exigem login.

## Experiência

- Página inicial com relógio em destaque e navegação responsiva.
- Busca e filtros por marca na curadoria.
- Página dedicada ao PRX Titanium, com quatro vistas, ampliação e navegação por teclado.
- Especificações em abas acessíveis, informações da peça e atendimento pelo WhatsApp.
- Barra de contato sempre acessível no celular.
- Animações com suporte a redução de movimento.

## Executar localmente

Site estático, sem dependências de build. Sirva esta pasta com um servidor HTTP:

```sh
python -m http.server 4173
```

Abra http://localhost:4173 . Edite os arquivos HTML, CSS e JavaScript diretamente. A publicação do GitHub Pages acompanha o branch `main`.

## Dados e limites

Esta é uma proposta independente de experiência digital, não o site oficial da marca e não uma loja com estoque integrado. Os preços foram consultados em 7 de outubro de 2026 e precisam ser confirmados. Os links de WhatsApp abrem o contato real publicado pela Alternativee; nenhuma mensagem é enviada automaticamente. Não há checkout, cobrança ou coleta de dados por formulário.

As páginas solicitam não indexação para identificar esta versão como demonstração.
